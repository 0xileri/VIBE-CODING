# ILERI — Portfolio

Personal portfolio for ILERI (@0xileri), a Web3 content creator and growth
specialist. Built with React + Vite.

## Sections

- Hero
- About
- By the Numbers (audience & collaboration stats)
- Notable Achievements (bounty wins & placements)
- Proof of Work (placeholder gallery for screenshots/certificates)
- Contact

## Editing content

All copy — name, bio, stats, achievements, proof-of-work entries, contact
links — lives in [`src/data.js`](src/data.js). Update that file to change the
site's content without touching components or styles.

## Development

```bash
npm install
npm run dev
```
